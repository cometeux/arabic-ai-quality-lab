# Action Review

Arabic-first task-quality prototype. Checks explicit owners, valid due dates, selected vague phrases, relative dates and possible multiple actions. Export the record and review flags as JSON.

This uses deterministic heuristics, not an AI extraction model. Flags may be wrong and can miss problems. Passing rules is not approval. It does not infer missing owners or dates.

Created November 2026 for Deema Alrafi with AI coding assistance. No employer data. Input stays within the browser application's memory unless you choose to export it; the hosting provider may collect normal access logs.
