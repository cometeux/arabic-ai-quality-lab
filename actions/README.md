# After the meeting · Action Review

An Arabic meeting-task notebook. Edit the task, owner and deadline, inspect review flags, undo deletion, and export the whole list.

Checks use explicit rules. They can miss problems or flag wording that is appropriate in context. Passing checks does not approve a task. There is no audio transcription, model-based task extraction or automatic assignment.

Input stays in page memory until exported or the page is closed. Application code makes no inference API calls. Hosting providers may collect ordinary access logs.

Version 0.2. [Code, decisions, verification and limitations](https://github.com/cometeux/arabic-ai-quality-lab).

Created for Deema Alrafi with AI coding assistance. All bundled examples are synthetic.
